# B8A1 — Problem Solving with TypeScript & OOP

This repository contains my solutions for the B8A1 assignment. The assignment covers core TypeScript concepts like basic types, optional and rest parameters, readonly tuples, interfaces, type narrowing, generics, Promises, and OOP.

## Files

- [`solutions.ts`](./solutions.ts) — solutions to all 8 coding problems.
- [`type-vs-interface.md`](./type-vs-interface.md) — blog post on the differences between `type` aliases and `interface`.
- [`union-intersection.md`](./union-intersection.md) — blog post on union (`|`) and intersection (`&`) types.

## Topics covered

- Optional, default, and rest parameters
- Readonly tuples and interfaces
- Type narrowing and generics
- Promises and async/await
- Classes, inheritance, and access modifiers
